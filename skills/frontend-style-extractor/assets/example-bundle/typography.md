# Typography

- `typography.body.family`: Inter, Arial, sans-serif (`typography.body.base`). Source CSS imports no bundled font; a target must have lawful access to Inter or use fallback.
- `typography.body.size`: 16px.
- `typography.heading.h1.size`: 32px, line-height 1.2 (`src/styles.css:15`).
- Other heading sizes and UI label styles: not established.
